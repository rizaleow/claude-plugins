# claude-plugins

Personal Claude Code plugin marketplace by [@rizaleow](https://github.com/rizaleow).

## Install the marketplace

```sh
/plugin marketplace add rizaleow/claude-plugins
```

## Plugins

| Plugin | Description |
| --- | --- |
| [`hostinger-cli`](./plugins/hostinger-cli/) | Skills for managing Hostinger VPS, DNS, and domains via the [`hostinger-cli`](https://github.com/rizaleow/hostinger-cli) binary. |
| [`filament-boost`](./plugins/filament-boost/) | Filament v5 expert mode: commands, agents, skills, and a lint-on-edit hook that ride on top of [Laravel Boost](https://github.com/laravel/boost) and the [`rizaleow/filament-boost`](https://github.com/rizaleow/filament-boost) Composer package. |

Install any plugin from this marketplace with:

```sh
/plugin install <plugin-name>@rizaleow
```
